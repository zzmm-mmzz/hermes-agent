# 情报中心对外接口文档

> 网关版本：Powermate 版 Hermes Agent
> 基础地址：`http://<网关IP>:8642`
> 后端情报中心配置：`intelligence/config.toml` 中 `base_url` 字段（当前 `http://127.0.0.1:10010`）
> Docker 部署时可用环境变量 `INTELLIGENCE_BASE_URL` 覆盖

---

## 通用约定

| 项目 | 说明 |
|------|------|
| 请求方式 | GET |
| 内容类型 | application/json |
| 成功返回 | `{"success": true, "code": 200, "data": ...}` |
| 失败返回 | `{"success": false, "error": "..."}`，HTTP 状态码 400/404/500 |
| 鉴权 | 如配置了 `client_id` / `client_secret`，网关自动先调情报中心 `/api/auth/token` 获取 Bearer token 再转发请求，对调用方透明 |

---

## 1. 资讯列表

获取资讯列表（列表接口不含 `content` 全文）。

**请求**

```
GET /api/intelligence/list
```

**查询参数**（全部可选）

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| page | int | 否 | 1 | 页码 |
| limit | int | 否 | 10 | 每页条数 |
| category | string | 否 | - | 栏目分类名，如 `电力要闻` |

**示例**

```
GET /api/intelligence/list?page=1&limit=10&category=电力要闻
```

**成功响应**

```json
{
  "success": true,
  "code": 200,
  "data": [
    {
      "id": "123456",
      "title": "国网湖南电力迎峰度夏保供电",
      "summary": "摘要内容...",
      "category": "电力要闻",
      "status": "已发布",
      "publishTime": "2026-07-28 10:00:00",
      "author": "某某部门",
      "source": "来源",
      "viewCount": 1024,
      "hasDetail": true
    }
  ],
  "total": 5,
  "page": 1,
  "limit": 10
}
```

**data 数组字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 资讯 ID |
| title | string | 标题 |
| summary | string | 摘要 |
| category | string | 栏目分类 |
| status | string | 状态（已发布） |
| publishTime | string | 发布时间 |
| author | string | 作者 |
| source | string | 来源 |
| viewCount | int | 浏览量 |
| hasDetail | bool | 是否有详情（true） |

## 2. 资讯详情

获取单条资讯完整内容（含 `content` 全文）。

**请求**

```
GET /api/intelligence/detail?id={id}
```

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 资讯 ID（来自列表接口的 `id` 字段） |

**示例**

```
GET /api/intelligence/detail?id=123456
```

**成功响应**

```json
{
  "success": true,
  "code": 200,
  "data": {
    "id": "123456",
    "title": "国网湖南电力迎峰度夏保供电",
    "summary": "摘要内容...",
    "content": "正文全文内容...",
    "category": "电力要闻",
    "status": "已发布",
    "publishTime": "2026-07-28 10:00:00",
    "author": "某某部门",
    "source": "来源",
    "viewCount": 1024,
    "hasDetail": true
  }
}
```

**data 字段说明**

同列表接口，额外增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| content | string | 资讯正文全文 |

---

## 3. 栏目分类

获取全部栏目分类及每个分类的资讯数量。

**请求**

```
GET /api/intelligence/categories
```

**成功响应**

```json
{
  "success": true,
  "code": 200,
  "data": [
    { "name": "电力要闻", "count": 2 },
    { "name": "政策法规", "count": 5 },
    { "name": "技术前沿", "count": 3 }
  ]
}
```

**data 字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 栏目名称 |
| count | int | 该栏目下资讯数量 |

---

## 4. 错误响应示例

```json
// 404 - 资讯不存在
{ "success": false, "error": "资讯不存在: 123456" }

// 400 - 缺少必填参数
{ "success": false, "error": "缺少 id 参数" }

// 500 - 情报中心服务不可达
{ "success": false, "error": "情报中心连接失败: Connection refused" }
```

---

## 配置说明

配置文件：`intelligence/config.toml`

```toml
[intelligence]
base_url = "http://127.0.0.1:10010"
client_id = ""
client_secret = ""
```

| 字段 | 说明 |
|------|------|
| base_url | 情报中心服务地址（IP + 端口） |
| client_id | 客户端 ID（可选，用于获取 token） |
| client_secret | 客户端密钥（可选） |

> 注意：修改 `config.toml` 后需重新构建镜像生效；使用环境变量 `INTELLIGENCE_BASE_URL` 只需重启容器。
