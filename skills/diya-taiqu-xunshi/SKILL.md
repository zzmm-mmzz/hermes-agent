# 低压台区巡视自动化

通过 Playwright 浏览器自动化，完成低压台区巡视全流程：创建低压台区巡视计划工单，对历史已巡视完毕的工单进行评分。

## 前置条件

- Python 3.x 已安装
- Python 包：`playwright`, `lxml`, `pandas`, `openpyxl`, `pywin32`（已安装在 Hermes Agent 虚拟环境中）
- 技能目录下的 `scripts/` 文件夹包含所有 Python 文件

## 重要：从 Hermes Agent 会话执行时的注意事项

本技能在 `terminal(background=true)` 模式下通过 subprocess 调用指令。关键的坑：

- 必须使用 Hermes 虚拟环境的 Python

- 确认当前 Python 是否为 Venv

```bash
# 在 terminal 中运行
which python
# 应输出 /c/.hermes/hermes-agent/venv/Scripts/python
# 如果输出类似 /c/Python311/python 则说明不在 venv 中

# 查看 python 所在目录
python -c "import sys; print(sys.executable)"
```

## 执行流程

用户请求创建巡视计划时，按顺序逐步执行以下步骤。

### 0. 确认巡视信息

1. 用户提出创建低压台区巡视计划/工单时，执行脚本读取表格内容。

执行脚本命令模板：
```bash
cd /c/.hermes/skills/diya-taiqu-xunshi && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step import
```

在收到`全部校验通过`的回复后，输出模板：

```markdown
> 用户需要发起下周低压台区巡视计划，已自动获取台区计划列表。

```

没收到`全部校验通过`，而是其他错误信息时，直接原样输出：
模板如下:
{{std_out}}              <- std_out 控制台输出

2. 根据用户的回答，对刚才控制台接收到的表格中的`巡视子类`字段进行规则验证：

- 仅限于["迎峰度夏","迎峰度冬","夜间巡视","保电活动","重要节假日","鸟害","高温大负荷","暴雨","大风天气","台风","洪涝","雷电","覆冰","树竹","山火","外破","三级污秽及以上地区","监察巡视","故障巡视","灾后特巡","其他","频繁停电","线路台区供电质量异常","10kV配电架空线路重点设备","10kV电缆线路重点设备","站房重点设备"]中的一个，需完全一致，不一致则自行匹配并告知用户你已修改

规则完全满足后，以markdown表格的形式展现给用户，请用户确认信息是否准确，是否需要修改。如果需要修改，在修改后再次展示并要求确认。

表格格式（只有一个序号时，不展示 `序号` 列）：

```markdown
> 下周的巡视任务如下，请您确认，确认后将自动发起巡视计划创建。

```


|序号|台区编号|台区名称|所属线路|电能表总数|台区经理|巡视日期|巡视子类|
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
|1|000|xx村xx台区|xxx|123|xx|2026/07/30|迎峰度夏|


[ ] 1 确认
[ ] 0 取消


如果需修改时打印模板如下：

```markdown
> 好的，已收到您的反馈信息，xx从xx改为xx（例如：巡视子类从A改为B）

```


**除上述规定的模板外，不要输出其他任何内容。**


### 1. 创建巡视计划（配网微应用）

执行指令，自动打开 Chrome 浏览器，导航到内网登录页面，登录后跳转到配网微应用的巡视管理页面，进行参数选择和信息填写，最后创建巡视计划。

执行开始前打印模板如下：

```markdown
> 开始在配网微应用中创建低压台区巡视计划。

```

```bash
cd /c/.hermes/skills/diya-taiqu-xunshi && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step pms30
```

你**必须持续跟进指令运行状态5分钟，跟进期间不要说话**，在接收到 `巡视计划创建流程已结束` 的返回结果后，必须把工单编号展现给用户，告知在配网微应用中已完成低压台区巡视计划创建流程，此时流程才结束。

回复格式（如有巡视设备未选择到，则输出对应的控制台信息）：
```markdown
> 已为您在配网微应用中完成低压台区巡视计划创建，工单编号为xx
> 即将基于以上信息，在全量业务工单中同步创建工单。

```

然后直接进行第2步，无需确认。

**除上述规定的模板外，不要输出其他任何内容。**

### 2. 创建巡视工单（全量业务工单）

执行指令，会自动打开 Chrome 浏览器，导航到内网登录页面，登录后跳转到全量业务工单，然后根据上一步创建好的计划编号，创建巡视工单。


直接执行脚本命令模板：

```bash
cd /c/.hermes/skills/diya-taiqu-xunshi && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step yx20
```

你**必须持续跟进指令运行状态 5 分钟，跟进期间不要说话**，在接收到 `巡视计划创建流程已结束` 的返回结果后，必须把工单编号展现给用户，告知在全量业务工单中已完成巡视工单创建流程，此时流程才结束。

回复格式（只打印一行数据，但要展示全部的营销工单编号）：


|配网工单编号|营销工单编号|
|:-:|:-:|:-:|
|PLxx|WK01<br>WK02<br>WK03|


```markdown
> 低压台区巡视计划创建完成。

```

**除上述规定的模板外，不要输出其他任何内容。**

此时所有流程结束。

## 注意事项

- 禁止向用户提示安装环境、更新系统、下载软件包或修改配置文件——用户明确要求不要让他们去执行这些操作。缺少依赖时直接说明因缺少 XX 导致流程执行失败即可。
- 所有数据和中间文件均保存在技能目录下。
- 执行失败时反馈错误信息，禁止修改 `scripts/` 目录下的任何文件，也禁止新增任何文件，如果是临时文件则需要及时删除。
- 禁止修改 `SKILL.md` 文件，如果需要改动技能描述，必须另存为新文件 `SKILL-yyyyMMdd-HHmmss.md`

### 内网环境执行要点（用户偏好）

- **禁止执行环境/依赖检查**：内网无法访问外网 `pypi.org`，`pip install` 会因 DNS 解析失败卡住。直接执行指令即可，缺少依赖由用户自行处理。
- **禁止请求主线操作者更改系统配置**：包括安装包、更新环境变量、修改系统设置等。不要让用户去操作他的终端环境。
- 用户偏好简洁直接，使用后台执行 + 每 20 秒检查输出的方式跟踪指令运行状态，跟踪期间不要说话。
