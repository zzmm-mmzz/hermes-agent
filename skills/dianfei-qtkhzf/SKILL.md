# 其他客户走访全流程自动化

通过 Playwright 浏览器自动化脚本，其他客户走访全流程自动化。操作内网供电系统，创建其他客户走访工单并派单给指定接单人员，以及对已完成工单进行审批。

## 前置条件

- Python 3.x 已安装
- Python 包：`playwright`, `lxml`, `pandas`, `openpyxl`, `pywin32`（安装在 Hermes Agent 虚拟环境中）
- Playwright 浏览器：`python -m playwright install chromium`
- Chrome 浏览器已安装
- 技能目录下的 `references/` 文件夹包含所有脚本

## Red Line
**禁止** llm返回内容禁止包含`脚本`、`账号`、`密码` 等
**禁止** 输出控制台数据前，禁止出现类似`脚本已完成，读取完整输出`等话术
**禁止** 脚本执行前，禁止出现类似`脚本正在执行`等话术
**禁止** 输出控制台内容时，不得添加任何前置描述文字（如"控制台输出如下："、"脚本输出："等），直接原样呈现
**禁止** 使用代码块（```）包裹控制台输出内容，必须以普通文本段落原样呈现
**禁止** 展示催费员账号和供电所信息
**禁止** 禁止检查python语法
**禁止** 重试失败`禁止自动重试`

## 重要：从 Hermes Agent 会话执行时的注意事项

本技能在 `terminal(background=true)` 模式下通过 subprocess 调用脚本。关键的坑：

- 必须使用 Hermes 虚拟环境的 Python

- 确认当前 Python 是否为 Venv：

```bash
# 在 terminal 中运行
which python
# 应输出 /c/.hermes/hermes-agent/venv/Scripts/python
# 如果输出类似 /c/Python311/python 则说明不在 venv 中

# 查看 python 所在目录
python -c "import sys; print(sys.executable)"
```

## 执行流程
**注意：控制台不能出现脚本2个字。**

用户请求其他客户走访时，按顺序逐步执行以下步骤。每步执行前告知用户该步骤的操作说明以及标题，执行完成后以markdown格式输出控制台内容，并解读生成文件。

每一步执行完成后必须主动读取并汇报控制台输出和生成的文件明细，不能等到所有步骤完成才汇总。

**静默执行定义：** 每一步执行完成后必须主动读取并汇报控制台输出和生成的文件明细，不能等到所有步骤完成才汇总。
**禁止** 修改skill.md文件和python文件

### 1. 创建其他客户走访工单

#### 1.1 询问用户用电户编号

直接向用户发问，由助手（Assistant）询问用户，不需要调用脚本或 tool。

提问模板：
```
请问您需要对哪个客户开展客户走访？
```

检查是否获取到了以下内容:
- 用电户编号

如果有缺失，继续追问:
提问模板:
```
好的，请提供XXX(用电户编号)。
```
**注意：控制台不能出现脚本2个字，所有的脚本都替换成任务。**

**静默执行定义：** "每一步执行完成后必须主动读取并汇报控制台输出和生成的文件明细，不能等到所有步骤完成才汇总。
**禁止** 修改skill.md文件和python文件

#### 1.2 创建其他客户走访工单

**注意：控制台不能出现脚本2个字。**

问完了请问您需要对哪个客户开展客户走访以后必须要问下面这个才能执行脚本
```
已创建其他客户走访任务，请问您要指派哪位人员接单？
```
**注意：控制台不能出现脚本2个字。**
用户提供接单人员（如：邓某（dengq123））后，执行派单脚本：

```bash
cd /c/.hermes/skills/dianfei-qtkhzf && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step qtkhzf --empl <接单人员工号> --cons_no <用电户编号>
```

执行完成后回复实例如下\n```\n好的，执行选择派工人员给邓某（dengw123），完成派单。\n``` 
只能输入以上模板，不能输出其他任何东西

### 内网环境执行要点（用户偏好）

- **禁止执行环境/依赖检查**：内网无法访问外网 pypi.org，pip install 会因 DNS 解析失败卡住。**用户反复强调不要检查依赖**——直接执行脚本，缺少依赖由用户自行处理。
- **禁止请求主线操作者更改系统配置**：包括安装包、更新环境变量、修改系统设置等。不要让用户去操作他的终端环境。
