# 电话号码核实自动化

通过 Playwright 浏览器自动化脚本，完成电话号码核实全流程。操作内网供电系统，创建电话号码核实工单并派单给指定接单人员，以及对已完成工单进行审批。

## 前置条件

- Python 3.x 已安装
- Python 包：`playwright`, `lxml`, `pandas`, `openpyxl`, `pywin32`（已安装在 Hermes Agent 虚拟环境中）
- 技能目录下的 `scripts/` 文件夹包含所有脚本

## Red Line
**禁止** 返回内容禁止包含`脚本`、`账号`、`密码` 等
**禁止** 输出控制台数据前，禁止出现类似`脚本已完成，读取完整输出`等话术
**禁止** 脚本执行前，禁止出现类似`脚本正在执行`等话术
**禁止** 输出控制台内容时，不得添加任何前置描述文字（如"控制台输出如下："、"脚本输出："等），直接原样呈现
**禁止** 使用代码块（```）包裹控制台输出内容，必须以普通文本段落原样呈现
**禁止** 展示催费员账号和供电所信息
**禁止** 禁止检查python语法
**禁止** 重试失败`禁止自动重试`

## 重要：从 Hermes Agent 会话执行时的注意事项

本技能在 `terminal(background=true)` 模式下通过 subprocess 调用脚本。关键的坑：

- 必须使用 Hermes 虚拟环境的 Python

- 确认当前 Python 是否为 Venv：

```bash
# 在 terminal 中运行
which python
# 应输出 /c/.hermes/hermes-agent/venv/Scripts/python
# 如果输出类似 /c/Python311/python 则说明不在 venv 中

# 查看 python 所在目录
python -c "import sys; print(sys.executable)"
```

## 执行流程

用户请求电话号码核实时，按顺序逐步执行以下步骤。每步执行前告知用户该步骤的操作说明以及标题，执行完成后以markdown格式输出控制台内容，并解读生成文件。

每一步执行完成后必须主动读取并汇报控制台输出和生成的文件明细，不能等到所有步骤完成才汇总。

**静默执行定义：** 每一步执行完成后必须主动读取并汇报控制台输出和生成的文件明细，不能等到所有步骤完成才汇总。
**禁止** 修改skill.md文件和python文件

### 1. 创建电话号码核实工单

#### 1.1 询问用户信息

直接向用户依次询问用户姓名、用电户编号、待核实电话号码，不需要调用脚本或 tool。

提问模板：
```
请提供用户姓名和用电户编号。
```

用户回复后，继续追问： 
```
好的，请问要核实的电话号码是什么？
```

检查是否获取到了以下内容:
- 用户姓名
- 用电户编号 <- **要求** 43开头的数字
- 电话号码 <- **要求** 1开头的11位数字或者7位数字或者8位数字

如果有缺失，继续追问:
```
好的，请提供XXX(用户姓名|用电户编号|电话号码)。
```

#### 1.2 查询档案内电话号码

信息收集完成后**直接执行脚本**，**禁止**输出任何前置语句（如"好的，信息已收集"、"即将执行创建工单脚本"、"脚本正在执行"等话术），**禁止**向用户展示收集到的信息或进行确认。

执行脚本命令模板：
```bash
cd /c/.hermes/skills/dianfei-dhhmhs && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step phone --cons_no <用电户编号> --phone <待核实电话>
```

**注意：执行完成后必须直接原样输出脚本控制台内容，不得自行组织语言或改写。** 禁止额外出现"脚本控制台输出"等描述文字。

模板如下:
{{std_out}}              <- std_out 控制台输出

#### 1.3 询问用户确认并选择接单人员，然后执行创建工单脚本

展示完脚本原始输出后，再询问用户：
```
请问是否需要发起电话号码核实工单创建？
[ ] 1 确认
[ ] 0 取消
```

用户确认后：
```
好的，请选择电话号码核实工单的接单人员。
```


用户提供接单人员（如：邓某（dengq123））后，直接按照以下模板输出前置语句：
`好的，执行选择接单人员给邓某（dengq123），完成派单。`
注意：前置语句输出后立即执行派单脚本，不得添加任何思考、内部提示或额外文字。

```bash
cd /c/.hermes/skills/dianfei-dhhmhs && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step dhhm --cons_no <用电户编号> --phone <步骤1.2的待核实电话> --doc_phone <步骤1.2查到的档案电话> --empl <接单人员工号> 
```

执行完成后以`markdown 表格格式`展示控制台输出结果。
示例如下:
```markdown
| 序号 | 工单编号 | 用户名称 | 接单人员 |
| --- | --- | --- | --- |
| 1 | WK4320202600001 | 李某某 | Dengq123 |
```

控制台输出内容输出后，输出统计信息，示例如下:
```
已创建1条电话号码核实工单。
推荐1： 发起历史已完成工单审批
推荐2： 关闭当前会话
```

### 2. 工单审批

用户提出审批需求时（如"发起电话号码核实工单审批"），执行审批流程。

#### 2.1 获取待审批工单清单

执行脚本查询待审批工单，并输出控制台内容：
```bash
cd /c/.hermes/skills/dianfei-dhhmhs && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step pre_audit
```
执行结束后，先执行前置输出语句。
前置输出语句示例如下:
`用户需要对历史已完成电话号码核实工单开展审批。执行中，查询到有3个工单状态为待审批。`

前置输出语句输出完成后，立即输出控制台内容

**注意：执行完成后必须直接原样输出脚本控制台内容，不得自行组织语言或改写。**
**禁止** 输出表可能为空，禁止检查输出表格

以`markdown表格形式`展示待审批工单列表给用户确认：   <- **要求** 所有控制台输出的符合markdown 表格格式的数据都要输出，**禁止** 省略
示例如下:
```markdown
| 序号 | 工单编号 | 工单内容 | 用户名称 | 处理员 |
|:-:|:-:|:-:|:-:|:-:|
| 1 | WK4320202600001 | 1222XXXX | 李某某 | 张三 |
| 2 | WK4320202600002 | 123XXXXX | 张某 | 李四 |
| 3 | WK4320202600003 | 12222XXXX | 章某 | 王五 |
```

控制台输出完成后，需要用户确认：
确认模板如下:
`请确认审批哪些工单？`

**步骤2.1的数据修改处理（重要）：** 若用户要求筛选具体某些条数的工单数据，必须将`待审核工单.xlsx`先备份，然后按用户要求操作`待审核工单.xlsx`数据，操作完成后必需按照`#### 2.1 获取待审批工单清单`中的要求展示`markdown 表格`和`确认信息`。数据操作要加载 `excel-pandas-processing` 技能，调用 `process_excel()` 函数处理。
**重要** 用户筛选是为**修改**,按上面的步骤来。
**重要** 修改后数据展示的模板与`#### 2.1 获取待审批工单清单`中的`markdown 表格`一致
**重要** 修改后用户确认格式与`#### 2.1 获取待审批工单清单`中的`用户确认格式一致`

#### 2.2 用户确认后执行审批

用户确认审批的工单后，执行审批脚本：   <- 必须执行
```bash
cd /c/.hermes/skills/dianfei-dhhmhs && /c/.hermes/hermes-agent/venv/Scripts/python.exe run.py --step audit
```

告知用户审批完成。
告知模板:
```
好的，已完成审批。
```
